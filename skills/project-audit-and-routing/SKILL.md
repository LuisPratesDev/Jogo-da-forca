# Auditoria e encaminhamento

Faça uma revisão integrada dos arquivos e dos fluxos relevantes para a tarefa. Priorize defeitos acionáveis por impacto, probabilidade e evidência. Não repita o mesmo problema em várias áreas.

Para cada achado, indique severidade, localização, condição de ocorrência e correção esperada. Encaminhe HTML/SVG semântico para HTML, aparência/layout para CSS e lógica/estado/testes para JavaScript. Não encaminhe opinião estética como defeito funcional. Preserve o contexto original e peça ao agente responsável a menor correção necessária.
