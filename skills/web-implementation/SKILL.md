# HTML, CSS e SVG

Siga as tecnologias e os padrões já usados no projeto. HTML deve expressar a semântica correta e manter uma ordem de leitura útil. CSS deve ser responsivo, previsível e reutilizar tokens existentes. SVG deve ter viewBox, dimensões escaláveis e nomes acessíveis quando transmitir informação.

Evite handlers inline, SVG com scripts ou referências externas inesperadas. Em revisões, verifique semântica, acessibilidade, overflow em telas estreitas, especificidade CSS, estados interativos e suporte a movimento reduzido. Prefira correções localizadas e cite evidências.
